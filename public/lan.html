LAN mode.
No install. No addresses.

The host tab becomes the referee directly over Wi-Fi — like Mini Militia, one device hosts and the rest join it. Everyone loads the site once (needs internet once), then every buzz travels straight to the host tab on the local network. There are no IP addresses to type and nothing in the QR but a room code, so the old 169.254 timeout problem cannot happen.

Event-day setup · 3 steps
01Host laptop connects to a Wi-Fi network (venue router or a phone hotspot — that network becomes the event network) and opens Host → LAN mode → Create room
02Contestants join that same Wi-Fi and scan the host QR — or open Contestant → LAN room and enter the code
03Quizmaster opens Quizmaster → LAN room, enters code plus the host PIN. Keep the host tab frontmost.
When to use Internet mode instead

If everyone is not on the same Wi-Fi (e.g. playing over mobile data), host an Internet room instead — the room lives on the timing server. Same 4 lobby options; the host picks the mode before creating.

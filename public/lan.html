LAN mode.
Buzzer packets stay in the room.

The Vercel link sends every press over the internet (delay + jitter). In LAN mode the event laptop runs npm start and every terminal talks to it directly over event Wi-Fi — typically single-digit milliseconds. Join with the room code plus the host LAN address.

Join a LAN room

Event-day setup · 3 steps
01Host laptop joins event Wi-Fi, runs npm start — note the LAN line, e.g. http://192.168.1.20:3000. It must be 192.168.x.x / 10.x.x.x — if it shows 169.254.x.x the laptop got no Wi-Fi address: rejoin the Wi-Fi (phones time out on 169.254 links).
02Open that LAN address on the laptop (/host.html), Create room — QR + code are LAN links
03Teams join the same Wi-Fi, enter the IP + room code above (or scan the host QR). No mobile data needed.

Why a redirect? An https:// internet page is blocked by browsers from talking to a http:// LAN host. So LAN mode navigates you onto the LAN address first — after that, everything (socket, sync, buzz) is LAN-local. If you are already on the LAN address, just join with the code.
